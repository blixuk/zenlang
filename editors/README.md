# Editor support for Zenlang

| Editor | Path | Install |
|--------|------|---------|
| **VS Code / Cursor / Antigravity** | [`vscode/`](vscode/) | `./scripts/setup_vscode_extension.sh` then reload window |
| **Zed** | [`zed/`](zed/) | `./scripts/setup_zed_extension.sh` then Install Dev Extension → `editors/zed` |
| **Tree-sitter grammar** | [`tree-sitter-zen/`](tree-sitter-zen/) | Generated by the Zed setup script |
| **Sublime Text** | [`sublime/`](sublime/) | Symlink `zenlang.sublime-syntax` into Packages |

## One-shot setup

```bash
# From repo root
./scripts/setup_vscode_extension.sh
./scripts/setup_zed_extension.sh
```

### VS Code family

Reload window → open `examples/getting_started/01_hello.zl` → language **Zenlang**.

### Zed

Extensions → **Install Dev Extension…** → choose `editors/zed`.

> **Note:** Zed needs a real git `rev` for the grammar (not `"local"`). The setup script commits the grammar into a nested repo under `tree-sitter-zen/` for local installs only.

## Keeping syntax in sync

When adding keywords or operators, update:

1. `vscode/syntaxes/zen.tmLanguage.json`
2. `tree-sitter-zen/grammar.js` → re-run `./scripts/setup_zed_extension.sh`
3. `tree-sitter-zen/queries/*.scm` (copied into Zed automatically)
4. `sublime/zenlang.sublime-syntax`
5. VS Code snippets / completions if needed
