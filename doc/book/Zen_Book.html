Chapter 2: Visual Data Flow

Zenlang is founded on the principle of directional clarity: code syntax reflects the physical movement of data through variables, transformations, and function returns.

1. The Assignment Arrow (->)

Values flow left-to-right into their variable targets. Use let for mutable bindings and set for immutable constants:

let score -> 100
score -> score + 25

set MAX_LIMIT : Integer -> 500

2. The Return Arrow (<-)

Functions emit results outward to their caller using the visual return arrow:

function multiply(a: Integer, b: Integer) : Integer {
    <- a * b
}

Sentinels: Nothing vs Default

Nothing denotes absence of a value (null/nil replacement). Default represents the type-declared zero state (0, 0.0, empty string, [], {}).

let avatar : String  -> Nothing  // Explicit absent state
let buffer : List    -> Default  // Materializes as []
let count  : Integer -> Default  // Materializes as 0

Type Casting (<: and Type(val))

let b : Byte -> 0x41
let int_val -> b <: Integer  // 65
let str_val -> b <: String   // `0x41`
let num     -> Integer(`42`)  // 42

Chapter 7: The Error Handling Triad

Zenlang rejects try/catch complexity, using an explicit error triad: raise (^), check (?), and assert (!).

function divide : [Decimal, Error] (a: Decimal, b: Decimal) {
    when b == 0.0 { ^ `DivisionByZero` with `Zero divisor` }
    <- a / b
}

// Graceful recovery:
let safe -> check divide(10.0, 0.0) or 0.0

// Invariant assertion:
assert safe >= 0.0 raise `NegativeResult`

Chapter 8: Modules, Namespaces & Packaging

Modules organize code cleanly with use, from, and import. Every file has access to an intrinsic module metadata object.

use zen.io
use zen.text.string as Str
from zen.math.math import abs, min, max

function main() {
    io.info(`Running module: ` + module.name)
    io.info(`Canonical path: ` + module.path)
    <- 0
}

Chapter 9: Terminal Mastery & UI Canvas

Zenlang is a terminal-first programming language. Sub-millisecond ANSI canvas rendering, 60 FPS redraws, raw keyboard polling, and layout widgets are native standard library primitives.

use zen.ui.canvas as canvas
use zen.sys.term as term

function main() {
    let cv -> canvas.create(80, 24)
    canvas.draw_box(cv, 0, 0, 79, 23, `rounded`)
    canvas.draw_text(cv, 10, 5, `* Zenlang Terminal Canvas *`)
    canvas.render(cv)
    <- 0
}

Chapter 12: Concurrency & The Unified Task Substrate

Zenlang eliminates the Function Color Problem (async/await) with a single task primitive running on lightweight M:N runtime fibers.

task fetch_profile : String (id: Integer) {
    <- net.get(`https://api.example.com/users/` + Str.to_string(id))
}

function main() {
    let h1 -> fetch_profile(101).spawn
    let h2 -> fetch_profile(102).spawn

    let p1 -> h1.wait
    let p2 -> h2.wait
    io.writeln(`Profiles loaded cleanly`)
    <- 0
}

Structured Concurrency with with task_group

Child tasks are bounded to their parent group lifetime. Any unhandled error cancels sibling tasks automatically with zero orphaned fibers.
